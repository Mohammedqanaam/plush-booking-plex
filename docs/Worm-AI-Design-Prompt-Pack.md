# Worm-AI Design Prompt Pack

نسخة موحدة احترافية للبرومبتات مع تحسينات **Production Concept** لضمان مخرجات أقرب إلى واجهات تطبيق حقيقية.

## قواعد إلزامية تُضاف دائمًا للبرومبت
- real mobile app screen
- product UI
- clean information hierarchy
- Arabic RTL typography
- high usability
- dashboard app interface
- not poster
- not abstract art
- real app layout

وعند الحاجة لتقليل الزحام:
- minimal clutter, clean information hierarchy, spacious layout
