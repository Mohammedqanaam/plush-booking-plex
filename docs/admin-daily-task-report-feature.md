# قسم تقرير المهام اليومية لمشرف الحجز

## الهدف
إضافة قسم داخل لوحة الأدمن في Res-dashbord.com لتوليد تقرير المهام اليومية لمشرف الحجز من خلال تعبئة البيانات المتغيرة فقط، مع معاينة التقرير قبل التصدير، وأرشفة كل تقرير، وإمكانية إعادة تحميل ملف Excel لاحقًا.

## المسار المقترح

```txt
/admin/reservation-supervisor/daily-tasks
```

## الصلاحيات
القسم يظهر ويعمل فقط لصلاحيات:

- `admin`
- `super_admin`
- `reservation_manager`

الحماية يجب أن تكون من الواجهة ومن طبقة السيرفر/API، وليس فقط إخفاء الرابط.

## الوظائف المطلوبة

### 1. إنشاء تقرير جديد
حقول الإدخال:

- تاريخ التقرير
- فترة التقرير من / إلى
- اسم المشرف
- الجهة المستلمة
- مهام يومية ثابتة قابلة للتفعيل أو التعديل
- إضافة مهمة جديدة
- الشكاوى أو مشاكل الضيوف التي تم حلها
- الموظفون الذين تم تدريبهم أو دعمهم
- مؤشرات الواتساب: `Conversations`, `First Response`, `Resolution`, `Waiting`, `Resolved`
- رابط أو مرفق محادثات الواتساب

### 2. المهام الافتراضية

- متابعة المكالمات المفقودة والتواصل مع العملاء خلال فترة الشفت.
- متابعة واستقبال محادثات الواتساب عبر الرقم الموحد.
- متابعة البريد الإلكتروني والرد على الرسائل الواردة.
- متابعة ملاحظات الجودة لموظفي الحجز المركزي.
- تقديم الدعم وسحب المكالمات مع زملاء موظفي الحجز.
- مراجعة الحجوزات والمشاكل التشغيلية في النظام.
- تدريب أو دعم الموظفين وتدوين الملاحظات.

### 3. معاينة قبل التصدير
صفحة معاينة تعرض التقرير بنفس شكل ملف Excel تقريبًا:

- جدول أزرق رسمي.
- ترويسة أزرق غامق.
- صفوف متناوبة أزرق متوسط / أزرق فاتح.
- محاذاة وسط.
- حدود واضحة للخلايا.
- اتجاه عربي RTL.
- قسم مؤشرات الواتساب.
- خانة مرفق الواتساب.
- توقيع أسفل التقرير باسم:
  - Mohammed Aldosari
  - Central Reservation Supervisor
  - Boudl Hospitality Group

### 4. توليد Excel
زر: `توليد ملف Excel`

مواصفات ملف Excel:

- صيغة `.xlsx`.
- اتجاه RTL.
- دمج خلايا العناوين.
- ألوان مطابقة للتقارير السابقة.
- حدود سوداء للخلايا.
- خط رسمي واضح.
- تنسيق خلايا احترافي.
- خانة للمرفقات.
- جدول حالات / شكاوى.
- جدول مؤشرات واتساب.

### 5. أرشفة التقارير
بعد إنشاء التقرير يتم حفظه في قاعدة البيانات مع:

- رقم التقرير.
- تاريخ التقرير.
- اسم المشرف.
- عدد المهام.
- عدد الحالات المغلقة.
- رابط مرفق الواتساب.
- حالة التقرير: مسودة / مكتمل / مؤرشف.
- اسم المستخدم المنشئ.
- تاريخ الإنشاء والتحديث.

### 6. إدارة التقارير السابقة
قائمة داخل الأدمن تحتوي:

- عرض التقرير.
- تعديل التقرير.
- معاينة التقرير.
- إعادة تحميل Excel.
- حذف التقرير من الأدمن فقط.

## نموذج بيانات مقترح

```ts
export type DailyTaskReportStatus = "draft" | "completed" | "archived";

export type DailyTaskReport = {
  id: string;
  reportDate: string;
  periodFrom: string;
  periodTo: string;
  supervisorName: string;
  receiverName: string;
  whatsappAttachmentUrl?: string;
  tasks: DailyTaskItem[];
  cases: DailyTaskCase[];
  whatsappMetrics?: WhatsappMetrics;
  status: DailyTaskReportStatus;
  createdBy: string;
  createdAt: string;
  updatedAt: string;
};

export type DailyTaskItem = {
  id: string;
  order: number;
  text: string;
  category: "تشغيلي" | "حالة/متابعة" | "تدريب" | "إداري";
  status: "منجز" | "قيد المتابعة" | "مؤجل" | "جاهز للإرسال";
  isDefault: boolean;
};

export type DailyTaskCase = {
  id: string;
  branchName?: string;
  guestName?: string;
  reservationNumber?: string;
  caseType: string;
  actionTaken: string;
  status: "تم الحل" | "قيد المتابعة" | "تم التصعيد";
  notes?: string;
};

export type WhatsappMetrics = {
  conversations?: number;
  firstResponse?: string;
  resolution?: string;
  waiting?: string;
  resolved?: number;
};
```

## Acceptance Criteria

- [ ] يظهر القسم داخل لوحة الأدمن فقط.
- [ ] يستطيع المستخدم إنشاء تقرير جديد من بيانات متغيرة فقط.
- [ ] يمكن إضافة أو حذف أو تعديل المهام قبل الحفظ.
- [ ] توجد معاينة واضحة قبل توليد Excel.
- [ ] يتم توليد ملف Excel مطابق بصريًا للتصميم المطلوب.
- [ ] يتم حفظ التقرير في الأرشيف.
- [ ] يمكن إعادة تحميل Excel من الأرشيف.
- [ ] يمكن تعديل التقرير وإعادة توليد الملف.
- [ ] يمكن حذف التقرير من الأدمن فقط.
- [ ] يتم حفظ اسم منشئ التقرير وتاريخ الإنشاء.

## ملاحظة تنفيذية
الأولوية ليست توليد ملف Excel فقط، بل بناء سجل تشغيلي رسمي يمكن الرجوع له يوميًا بدل الاعتماد على الإيميلات واللقطات اليدوية.
